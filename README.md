# Stellar Burgers - Тестирование системы заказа бургеров

## 📋 Описание проекта
Проект представляет собой систему для заказа бургеров в Stellar Burgers. Основная цель - покрытие юнит-тестами класса `Burger` с использованием библиотек Mockito, JUnit 4 и параметризации.

## ✅ Выполненные требования

### 1. **100% покрытие класса Burger** ✅
- Все 6 публичных методов протестированы
- Все тестовые сценарии покрыты
- Отчет JaCoCo подтверждает 100% покрытие

### 2. **Использование Mockito** ✅
- Изоляция зависимостей через моки
- Базовый класс `BaseBurgerTest` с настройкой моков
- Тестирование в контролируемой среде

### 3. **Параметризованное тестирование** ✅
- `BurgerPriceParameterizedTest`: 5 различных комбинаций
- `BurgerReceiptParameterizedTest`: 4 набора данных

### 4. **Принцип "один тест - одна проверка"** ✅
- Каждый тест проверяет только одну ассерцию
- 39 тестовых методов, 58 запусков тестов
- Упрощенная отладка и читаемость
